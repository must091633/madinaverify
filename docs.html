Madinaverify API

REST API contract for identity and business verification integrations.

Security: Keep API keys on your server. Never expose them in browser JavaScript, public repositories or mobile client code.

Authentication

Send your API key in the Authorization header.

Authorization: Bearer YOUR_API_KEY

Health

GET /v1/health

Check API availability.

curl https://api.madinaverify.com.ng/v1/health

NIN Verification

POST /v1/verification/nin

Submit an authorized NIN verification request.

{
  "nin": "***********",
  "consent": true
}

BVN Verification

POST /v1/verification/bvn

Submit an authorized BVN verification request.

{
  "bvn": "***********",
  "consent": true
}

CAC Verification

POST /v1/verification/cac

Submit a company lookup/verification request.

{
  "registrationNumber": "RC0000000"
}

Errors
